HTML Heading Level 1 (H1)

This is the main heading of the page. Normally, a webpage should have only one H1 heading.

HTML Heading Level 2 (H2)

H2 is used for major sections of the webpage.

HTML Heading Level 3 (H3)

H3 is used for subsections under an H2 heading.

HTML Heading Level 4 (H4)

H4 represents a smaller subsection.

HTML Heading Level 5 (H5)

H5 is used for less important subheadings.

HTML Heading Level 6 (H6)

H6 is the smallest heading available in HTML.
